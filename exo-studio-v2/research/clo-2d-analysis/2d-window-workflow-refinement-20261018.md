# CLO 2D window workflow and ClothCraft refinement — 2026-10-18

## Official CLO references: location and semantics

The official [2D Vertical Toggle Icons](https://support.clo3d.com/hc/en-us/articles/360011148874-2D-Vertical-Toggle-Icons) documentation groups **Show Reference Line**, **Show Seam Allowance**, baselines and related pattern layers in the 2D Pattern display stack, separate from geometry authoring. [Show/Hide Seam Allowance](https://support.clo3d.com/hc/en-us/articles/115013215787-Show-Hide-Seam-Allowance) describes the 2D window display control and the corresponding Display menu command. [CLO Notch](https://support.clo3d.com/hc/en-us/articles/115015735467-Notch) and [2D Seam Allowance](https://support.clo3d.com/hc/en-us/articles/115015714428-2D-Seam-Allowance) are under 2D Pattern → Create and available in the 2D toolbar. In CLO, a seam allowance is a grey offset attached to a pattern edge or internal line. The selected allowance has properties in the Property Editor; EXO presently exposes numeric width through the left tool settings, while advanced join options remain future work.

The official [How to Edit Bézier Curves](https://support.clo3d.com/hc/en-us/articles/115002753388-How-to-Edit-B%C3%A9zier-Curves) locates curve editing under 2D Pattern → Edit → Edit Curve Point / Edit Pattern; selecting a curve exposes draggable handles. CLO includes modifier behaviors for independently changing curvature and for maintaining a handle angle. EXO now creates an editable native cubic with collinear control handles when a previously straight contour is clicked in Curve mode. Dragging the handle adjusts actual Rust polygon geometry. Exact CLO shortcut parity is not yet claimed.

Physical pattern **notches** differ from **directional sewing indicators**. [Notch](https://support.clo3d.com/hc/en-us/articles/115015735467-Notch) describes a red hover placement point, with selected notch highlighted in yellow; [Edit Notch Properties](https://support.clo3d.com/hc/en-us/articles/115015735687-Edit-Notch-Properties) includes type, angle, direction, flip and length. [Segment Sewing](https://support.clo3d.com/hc/en-us/articles/115012381248-Segment-Sewing) separately defines directional notches while matching two sewn segments. In the local screenshot, the shallow neckline and double red armhole markings favor a back-bodice interpretation (~85% confidence), but exact native CLO object identity remains unconfirmed without selecting the marks in CLO itself. See reference-semantic-diff.md.

## Implemented UI changes

The floating group of Reference guides, Native notches and Seam allowances buttons was removed. A **2D Pattern Display** icon now opens a compact flyout in the existing left vertical 2D tool rail. It controls visual Reference Lines, saved Internal Lines, Notches and Seam Allowance separately. Authoring continues through the tool families already present in the rail: select/edit, point, curve, internal line, notch and allowance. CLO's exact toggle collection differs in places; this is an EXO adaptation to its current data model.

The large on-canvas chest construction-guide measurement popup was removed entirely. Selecting any guide highlights its actual interval without covering the pattern. The selected name, measured 2D length and optional **Create native internal line** command appear inside the tool menu. A selected saved Rust internal line instead offers **Remove native internal line**.

Chest, belly, upper-hem and lower-hem horizontal guides each comprise two independently selectable intervals, from left endpoint to center and from center to right endpoint. They have exactly three visible shared dots. The dotted centerline is segmented at those same intersection coordinates, eliminating the previously doubled/orange point close to a crossing. Shoulder internal offset references now have endpoint dots and work with the same hover/click selection. This is based on actual rotated/translated pattern boundaries, with distance tests performed in screen pixels at any canvas zoom.

Native Rust InternalLine records now display independently for every panel type and keep source line IDs. New lines created from proportional references are explicit Rust edits with endpoints inset inside the cut outline. Saved line selection/visibility/removal are separate from visual guides, and users can hide reference lines without hiding source geometry.

The Curve tool materializes a two-handle Bézier control pair for an edge, including a neckline. Dragging a handle previews its movement and saves new numeric control coordinates with the native Rust Shape action.

Sample red armhole marks remain identified as **reference notch markings**. The basic tee follows the legacy front single / back double convention when an armhole or lower sleeve/underarm reference is present. This is a visual reference only: future unknown garment pieces must not be assigned imagined cutting notches. Real pattern notches use native Rust edge-relative stored positions. A Shift-click creates two separate stored marks for a double pair; Option-click removes the nearest selected mark. The Notches visibility control hides both the red sample markings and saved native marks, and real marks suppress the illustration on their host edge. Sewing direction remains an independent seam relation.

## Scope limits

- Rust EdgeNotch currently stores position and depth only; full CLO notch style, angle, flip, grading and atomic paired identity remain unimplemented. Two stored marks are a partial representation of a CLO double notch.
- Seam allowance outlines still need production-grade custom joins, self-intersection handling and graded DXF cutting output verification.
- Rust InternalLine supports tangent geometry, but the new 2D saved-line display currently connects stored anchors with straight segments. Fully matching curved internal-line samples and editable interior handles remains future work.
- Torso chest/belly proportional overlays are construction references, not approved factory POM values. Source-backed internal-line selection applies to arbitrary future patterns.
- The detached upper strip in the CLO reference likely represents some type of neck tape/binding but must be identified from selected native CLO properties before being treated as a known production piece.
