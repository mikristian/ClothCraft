# EXO ClothCraft Studio V2 — Current whole-app gap audit

**Date:** 2026-10-18 afternoon. **Scope:** current source and installed native backend, covering pattern CAD, 3D simulation, cloth/avatar physics, UI/tool parity, grading, factory exports, persistence, desktop deployment, and build/storage reliability. This is a read-only evaluation; no production project or app was changed. Prior detailed reports in this directory remain supporting evidence, but later implemented milestones have been credited below.

## Executive assessment

EXO has crossed an important architectural milestone: the Rust engine now offers `production-handoff`, an atomic **read-only**, revision-checked bundle of editable material geometry, seam/panel IDs, compiled 3D mesh, metrics and cutline/notch *proofs*. Its disposable edit→split→grade→mesh→cutline→Undo/Redo→Save/reopen acceptance test passes. But the installed macOS app is not yet rebuilt with that source change; the production UI still routes the user to a separate classic production workflow rather than offering the full native package. The largest remaining gaps are **physical simulation fidelity**, **factory-grade native CAD and grading**, and **complete product integration with release/persistence gates**. More toolbar icons are not a higher-leverage use of development effort.

## Build-order recommendation

**Milestone 1 — measurable fit (highest risk)**: establish fail-on-threshold physics/cloth/avatar/seam benchmarks and fix worst local strain/contact behaviors, before describing drape as accurate. Parallelize with exact factory constraints.

**Milestone 2 — manufacturer-ready 2D core**: build native parametric size-rule graph and complete cutline/notch/hole/grainline/POM semantics. Require same-revision DXF plus vendor-independent readback. Produce T-shirt + curved/darted jacket size-run exemplars, validated manually against printed scaling and CLO.

**Milestone 3 — close the user workflow**: wire existing native `production-handoff` into UI with true generated cutlines rather than reference SVG, multi-size review/export and release check. Build isolated QA AppKit, test physical window, then promote arm64 package only after backup/restart/signed integrity QA.

**Milestone 4 — preserve performance and expand tools**: improve incremental 2D/3D remeshing under edited sewing relationships, calibrate fabric presets, gradually complete high-value editing functions, long-session stress and reliable recovery. Finish architecture before cosmetic parity.

## Bottom line

EXO is already a functional CAD/simulation research system with a working revision-checked Rust document handoff. **It is not yet a validated manufacturer-ready CLO replacement.** The biggest gaps today are credible 3D fit, industrial 2D grading/export, and presenting those capabilities together in the actual installed app without reference loss. These are the major acceptance gates, not the number of visible toolbar buttons.
