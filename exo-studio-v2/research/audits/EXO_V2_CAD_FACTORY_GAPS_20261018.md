# EXO V2: CAD and factory delivery gap audit

Date: 2026-10-18. Scope: source-level review of native 2D authoring, topology, curves, constraints, grading, POM, notch/seam semantics, allowances, industrial DXF, factory PDFs, markers and tech packs. **No garment or application code was modified.** This is a static audit, not a factory certification or a claim that all regressions fail. Concurrent engineering work may change the files after this snapshot.

## Confirmed implemented surfaces and existing verification

The code **does** have real production functionality: `native_cpp/core/production_preflight.cpp:130-161,170-254` checks shape integrity, seams, size runs and marker placement; `native_cpp/core/factory_package_files.cpp:77-104` assembles structured tech-pack, CSV, DXF, marker and source artifacts; `native_cpp/core/dxf_export.cpp:42-90` writes physical-unit cutting polylines; `native_cpp/core/grading.cpp:195-283` evaluates graded sizes; and `rust/exo_geometry_kernel/src/lib.rs:107-140` contains numerical geometry unit tests. Source test files additionally exist for grading, drafting split, production preflight, seam assembly, marker PDF, DXF-related factory packages, factory ZIP and graded geometry bridge (`native_cpp/tests/test_grading_helpers.cpp`, `test_drafting_split.cpp`, `test_production_preflight.cpp`, `test_marker_pdf.cpp`, `test_factory_package_files.cpp`, `test_factory_zip.cpp`, `test_graded_geometry_parity_bridge.cpp`). Their presence is **not** a fresh test result. No build or test was run during this constrained audit.

Prior recorded research in `research/OPEN_SOURCE_2D_PATTERN_AND_GRADING_DECISION_20261018.md:40-47` reports a passing GarmentCode adapter check with four panels, fourteen stitches and five curved front edges. That is limited adapter evidence, not a cross-vendor DXF or factory approval. The `research/clo-2d-analysis/exo2d-geometry-deep-audit-20261018.md` report identifies additional delete-point and curve split migration risks, which should be reproduced against the current head before treating them as confirmed active failures.

## Five highest-return milestones

1. **Canonical Rust PatternDocument and persistent topology IDs.** Specify immutable revision IDs, typed geometries, stable edge/point/seam/notch/POM links, legacy serialization, and deterministic source-to-export provenance. Gate migration on lossless round-trip fixtures.
2. **Atomic native edit/remap kernel.** Port insert/delete/split/mirror/unfold and free curve point operations, preserving seam intervals, matched notch stations, allowances, grade rules, internal markings and measurements. Include adversarial curved edits and reversible undo/save/reopen checks.
3. **Exact cutline and grading validation.** Produce per-edge allowance contours with measured deviation, robust corner/curve handling and entire multi-size propagation. Cross-check pattern perimeter, seam walk, POM and self-intersection after every size transform.
4. **Certified apparel export compatibility matrix.** Specify industrial AAMA/ASTM and generic DXF semantics, print/marker calibration, scale/unit/profile controls and machine-reader acceptance; test against at least two independent CAD programs and real plot measurements.
5. **Factory release gate with revision provenance.** Generate all artifact formats from a frozen, hashed production snapshot; run fatal referential-integrity checks, require reviewed exceptions for intended ease and mismatch, and include complete marker, tech-pack, POM, sewing and hardware sign-off evidence.

## Validation still missing

One end-to-end accepted reference suite should use a straight tee, curved-neck tee, darted bodice, complex asymmetric panel, lining/fusing set and five graded sizes. For each: edit and undo topology; export, reimport and recompute millimeter measurements; validate paired seam and notch station geometry; open DXF in two third-party apparel CAD consumers; print at 100% and physically measure; compare BOM/tech-pack/POM to the same revision; and verify marker constraints against the actual cutter or factory profile. Report tolerances, versioned oracle assets and reproducible commands. Until that suite passes, describe artifacts as **engineering outputs requiring factory review**, not certified manufacturing instructions.
