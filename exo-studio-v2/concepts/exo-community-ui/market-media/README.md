# EXO marketplace image previews

These compressed WebP previews are generated from assets already used by the EXO garment editor. To regenerate base scans/hardware thumbs, run `node concepts/exo-community-ui/scripts/build-marketplace-media.mjs` from the project root. This preserves independently generated `fabricBalls` and `appStages` in the JSON manifest.

**Fabric surfaces:** The sources are the local `public/fabric-scans` Poly Haven textile references and `public/fabric-scans-ambientcg` ambientCG CC0-1.0 assets. The mapping uses the app's `src/data/polyhavenFabricAssignments.js`, including its construction-proxy disclosures. Many of the 400 fabric finish records deliberately share a single family scan; the photos represent texture only, not certified fiber composition, color, weight, elasticity, or material physics. Three archetypes currently have no suitable photographic assignment and retain the procedural fallback.

**Draped sphere previews:** `scripts/render-market-fabric-balls.mjs` drives the actual `src/components/FabricDrapeBallPreview.jsx` Three.js viewer through a development-only Vite render harness on the existing `127.0.0.1:5188` project server. It generated 34 static optical drape-on-ball family thumbnails, used throughout many of the 400 reference variants; they are visual samples rather than physically simulated drapes or individual fabric swatch measurements. The static marketplace works without React/Vite.

**Hardware:** Actual visual thumbnails from `public/hardware-thumbnails` in the EXO app, for example zippers, buttons, and buttonholes. These previews do not grant product ownership or supplier rights.

**Studios:** Five quality scene posters (`EXO01`, `R02`, `R03`, `S01`, `S10`) are copies of existing EXO scene images in `public/stage-posters`. Their corresponding source scene files and readiness state are recorded in `public/stage-scenes/manifest.json`. The V2 curated preset officially approves `EXO01`; the other four are ready recovered EXO scene assets.

**Single garment image:** `nike-saved-native-render.webp` was freshly rendered using `scripts/render-market-native-nike.py` and Blender 5.1. It uses the installed EXO V2 project's actual `fitting-project.json` saved solver positions (2,533 mesh vertices), baked native mesh topology from that same project, its precise `Nike Swoosh · Example SVG` print artwork and millimetre placement, and the saved CC0 MakeHuman avatar OBJ. The render faithfully depicts these saved project elements but is **not** a direct screenshot of the open application window or a certified fitted garment. The programmatically assembled project snapshot and print source remain outside the public website; only the final WebP is served. The original older `nike-graphic.webp` is archival and is no longer referenced by marketplace listings or profiles. Nike is a third-party trademark; showing the render implies no affiliation, licensed merchandise or distribution rights.

The original CC0 Foundation Tee and Drawstring Pouch PDF sewing patterns are actual free downloads. All other marketplace listings remain view-only previews; no storefront purchasing, account inventory or entitlement service exists.
