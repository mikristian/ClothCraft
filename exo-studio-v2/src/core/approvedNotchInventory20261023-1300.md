# Authored notch approval contract — isolated experiment (2026-10-23 13:00)

`createApprovedNotchManifest20261023(project, sourceRevision)` creates a deterministic canonical JSON manifest and its SHA-256 fingerprint. The manifest contains source revision, base size, ordered size run, piece IDs, and per-piece authored notch IDs. The fingerprint is **only a self-hash**: an attacker can rewrite the inventory and recalculate SHA-256.

An independent approver must inspect the complete manifest against separately archived source/design records, establish that no notches or sizes have already disappeared, and sign the exact UTF-8 `signingPayload` with an authorized Ed25519 private key. Preserve an immutable approval record with approver identity, approval timestamp, design/source revision, the manifest bytes, its SHA-256, signature, and a link to reviewed source evidence. Store the signing private key outside the application and the editable garment/workspace; distribute the authorized public key through separately managed trusted configuration, ideally pinned with a recorded key fingerprint and rotation/revocation procedure.

`verifyApprovedNotchInventory20261023(project, sourceRevision, approval, trustedPublicKey)` checks manifest structure and unique IDs, compares complete ordered sizes and notch identities, verifies the SHA-256, and verifies the signature against the supplied public key. Missing/mismatched inputs block identity verification. The invoking application must independently attest the current `sourceRevision`, and independently pin the approver public key. A revision string taken from an attacker-editable project and a public key sent beside a forged approval **cannot establish trust**. The verifier cannot detect a deletion that happened *before* the first truly independent approval. The result `signed_inventory_identity_match` authenticates inventory only relative to the supplied key and source revision.

No production or release gate invokes this experimental module. It does not validate physical notch geometry, per-size grading or DXF marks, manufacturing output, sampled garments, or factory authorization; all factory flags remain false. Attestation of approver authority and review evidence remains an external operational requirement.
