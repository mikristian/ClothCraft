## Evidence and limits

This audit combines CLO's official product help with EXO's local, previously captured **CLO 7.0.242** accessibility-title inventory in `src/data/clo7ToolbarOrder.js:1-100`. The local inventory says its tool labels and x/y ordering were collected using a CLO inspector on 16 October; I have **not independently opened the installed CLO application** in this pass. `docs/CLO_V7_EXACT_DUAL_TOOLBAR_ORDER_2026-10-16.md:1-67` is an older screenshot interpretation and explicitly warns that icon-only identifications were uncertain; prefer the later accessibility-title manifest for the particular captured configuration. Do **not** call either a universal or up-to-date CLO default: CLO 2026.1 allows users to reorder, regroup and hide tools, and to reset to default. See [CLO Customize Toolbar](https://support.clo3d.com/hc/en-us/articles/59637467539225-Customize-Toolbar).

Official help establishes the separate **3D toolbar** and **2D toolbar**, rather than a single unified left bar: [CLO interface overview PDF](https://support.clo3d.com/hc/en-us/article_attachments/48293801440281), [Edit Pattern](https://support.clo3d.com/hc/en-us/articles/115012380108-Edit-Pattern), [Edit Sewing](https://support.clo3d.com/hc/en-us/articles/115012380148-Edit-Sewing), [3D Sewing](https://support.clo3d.com/hc/en-us/articles/360007863993-3D-Sewing), [Notch](https://support.clo3d.com/hc/en-us/articles/115015735467-Notch), and [Polygon Lasso Selection](https://support.clo3d.com/hc/en-us/articles/115004324447-Polygon-Lasso-Selection). Official help verifies tool families and functionality, **not** the full physical top-to-bottom order of this captured CLO 7 session.

## Which toolbar the user actually sees

* **EXO left of garment viewport:** `src/App.jsx:4782-4850` renders `<aside className="tool-rail">`, `clo-left-3d-double-bars` (independent A/B columns), additional EXO 3D actions and secondary 2D pattern shortcuts. This is the user-facing **left** toolbar. Manifest: `src/data/clo7ToolbarOrder.js:20-62`.
* **EXO right of viewport beside object/properties inspector:** `src/App.jsx:4956-4959` mounts `RightToolPalette`; `src/components/RightToolPalette.jsx:226-269` renders separate `CLO7_2D_A/B` reference strips, additional EXO tools or focused workspace groups. This is the user-facing **right** toolbar, despite the original request calling both sides 'left'. Manifest: `src/data/clo7ToolbarOrder.js:64-100`.
* **Embedded ClothCraft quick controls:** `src/components/ClothCraftCornerTools.jsx:7-33` delegates to `ViewportQuickTools.jsx:7-69`, which shows 2D and 3D flyout families inside the native workspace. These are distinct, reduced corner controls and should not be counted as complete CLO bars. Their 2D `point`, `split`, `curve`, `measure`, `select` all map to `edit` mode, so choosing each does **not** by itself establish five distinct Rust operations. `notch`, `pin`, and `fastener` in quick-tool flyout definitions are filtered out by `availableTools`.

## Verified wiring vs real feature support

`src/core/clo7NativeToolCapabilities.js:9-35` labels **17 native command slots** (eight 3D, nine 2D), **six inspect-only slots** and the remaining **47 unavailable** among the captured **70 positions** (38 3D + 32 2D). Note duplicate operations appear under different CLO slots (e.g., Segment and Free Sewing both use the current free-sew path), so 17 is **not** the count of independent capabilities. `src/core/clo7NativeToolCapabilities.js:37-81` includes honest limitations.

* Native-marked 3D positions: A01 simulate; A02 panel selection/placement; A05 edit an existing seam; A06/A07 sewing (shared underlying simplified seam operation); A13 reset 2D arrangement; A14 reset 3D arrangement; A15 re-drape. Other 3D positions are inspect-only (B07, A19, A20) or unavailable. The native declaration must be checked against executed Rust requests before promising parity.
* Native-marked 2D positions: A01 transform, A02 point edit, A04 polygon, A05 internal line, A08 persistent notch, A09 10 mm per-edge seam-allowance guide, B01 edit sewing, B02/B03 simplified sew. Inspect-only 2D: A11/A12 temporary measurement and B04 seam inspection. `src/components/RightToolPalette.jsx:147-185` forwards native reference buttons to `onCloTool` and directs many EXO extras into legacy editors or browser navigation.
* The native **notch** persists a boundary marking but is not a physical edge cutout; **seam allowance** is a cutting guide, not a changed sewn contour (`src/core/clo7NativeToolCapabilities.js:48-49`). Measurement preview is not an authored graded POM (`:56-58`). This distinction matters for manufacturing files.
* Opening Button, Zipper/Trim, Topstitch, Graphic, POM or Grading browser tabs through `RightToolPalette.jsx:171-175` does not make CLO's geometry-editing, 3D fastening, topstitch simulation, or grading operations functional in Rust V2. The EXO source explicitly marks unsupported `notch`, `pin` and `fastener` **extra** actions in native mode (`RightToolPalette.jsx:128,157-160`), while notch has a *separately* supported native reference slot `2d:A08`; these paths should be reconciled for consistent access and explanation.
* The bottom `RESET 3D/PANELS` action in `RightToolPalette.jsx:262` is a reset action, not a CLO toolbar slot. The mode selector changes between all/reference tools and focused EXO tools; `MAP` exposes currently unsupported CLO positions for explanation (`:226-259`). On initial default, unmatched slots are filtered out (`:245-246`), so **missing-looking tools may be intentionally hidden by the supported-only view**.
