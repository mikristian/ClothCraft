## Interaction and recreation guidance

`AXCheckBox` describes toggle/selectable actions such as `Select/Move`, `Edit Sewing` and `Steam`; `AXButton` describes immediate actions such as `Auto Sewing` and `Graphic (2D Pattern)`; `AXPopUpButton` identifies available popup affordances, including `Simulate`, `Select Mesh (Brush)`, `Segment Sewing`, `Free Sewing`, `Button` and `Tack`. These role labels are real evidence but do **not** prove that opening a control occurs via hover rather than click. Nor do they prove whether a popup opens directly to the right, displays a horizontal row, or supports delayed pointer entry. The user's described horizontal flyouts should therefore be treated as a design requirement awaiting native pointer-driven visual verification.

The closest evidence-backed reproduction is two compact vertical 34×30-point icon columns for each viewport, with 36-point horizontal origins, primarily 34-point vertical pitch and occasional 44-point group pitch, matching the command ordering independently per column. Retain dedicated focus/selected state for checkbox-type tools and menu indicators for popup-capable tools. Reuse the implementation's existing toolbar family definitions, but avoid inventing measured flyout dimensions, children or precise timings. To match the horizontal hover widget exactly, a later *authorized hover-enabled capture* must record the resting state, hovered anchor, opened menu, and pointer transfer into each flyout without clicking or changing CLO project data.

No CLO project actions, native UI clicks, permission changes or production-code modifications were made. This document is the only repository file added by this worker.

The current native AX report measures the **separate dark editing rails**, not those two mini-rails. This visual distinction is significant for recreating the widgets. Its current command catalog continues to serve editing modes; a precise one-for-one mapping to CLO's display/visibility controls remains unverified until a permitted live hover capture is available.
